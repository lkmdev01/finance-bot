## 📷 OCR - RECONHECIMENTO DE IMAGENS

### Enviar Imagem com Legenda

Envie uma imagem de nota fiscal, recibo ou comprovante com uma legenda descrevendo a transação:

```
[Imagem de nota fiscal] Gastei 150 reais no supermercado
[Imagem de recibo] Recebi 500 reais de pagamento
[Imagem de comprovante] Paguei 80 reais de conta
```

### Enviar Imagem sem Legenda (OCR Automático)

Envie apenas a imagem. O sistema tentará extrair o texto automaticamente:

```
[Envie apenas a imagem da nota fiscal/recibo/comprovante]
```

**Nota:** O OCR funciona melhor com:
- Notas fiscais claras
- Recibos legíveis
- Comprovantes com texto bem visível
- Imagens com boa qualidade e iluminação

## ⚠️ OBSERVAÇÕES IMPORTANTES

1. **Transações Grandes**: O sistema pode pedir confirmação para transações acima de R$ 1.000,00
2. **OCR**: Requer configuração da Google Vision API no `.env`
3. **Relatórios**: As URLs geradas requerem autenticação (usuário deve estar logado)
4. **Períodos**: Se não especificar, usa o mês atual por padrão
5. **Categorias**: O sistema tenta identificar automaticamente a categoria mais adequada

## 🐛 TESTES DE ERRO

Para testar tratamento de erros:

```
1. Envie mensagem vazia
2. Envie apenas emojis
3. Envie valores inválidos: "Gastei abc reais"
4. Envie comandos muito longos (mais de 1000 caracteres)
5. Envie imagem corrompida ou muito grande
```

## 📝 NOTAS FINAIS

- Todos os comandos são processados de forma assíncrona
- O sistema envia feedback imediato: "⏳ Processando sua mensagem..."
- As respostas são formatadas com emojis e formatação rica do WhatsApp
- O histórico de conversa é mantido para contexto
- O sistema aprende com o histórico para melhorar as respostas
